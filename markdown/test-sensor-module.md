# Blockage Detection Module Accuracy Test (Markdown)

Confirms that the Blockage Detection Module consistently identifies blockages in coronary arteries with high accuracy.

## Steps
1. Load CT scan data with confirmed blockages into the Blockage Detection Module.
2. Run the module and capture identified blockage locations.
3. Compare the detected blockages against the confirmed blockages in the dataset.
4. Calculate detection accuracy and false-positive/false-negative rates.
5. Record the findings, ensuring accuracy meets clinical standards.
